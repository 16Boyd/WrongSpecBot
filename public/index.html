WrongSpecBot

A Discord bot for World of Warcraft token prices and live game-server status.

WrongSpecBot runs as a set of serverless endpoints on Vercel and answers Discord slash commands and button clicks. A Cloudflare Worker triggers it on a schedule to check prices, realm status, and game-server status, then posts or updates messages in Discord.

What it does

📊 WoW Token prices

Tracks the WoW Token price across US, EU, KR, and TW, on demand or on a schedule.

🔔 Price alerts

Posts a channel alert when the token crosses a configurable sell or hold threshold.

🌍 Realm status

Monitors WoW realm up/down status and reports changes to a Discord channel.

🖥️ Game-server status

Shows live AMP game-server status with a one-click Start Server button to boot an auto-stopped instance.

Slash commands

  • /token [region] — current WoW Token price for a region
  • /notify <channel> <sell> <hold> — set up price alerts

Run your own

WrongSpecBot is open source. You can fork the repository and deploy your own instance — with your own Discord bot, Blizzard API keys, and (optionally) your own AMP game server. See the Run Your Own Instance guide in the README for step-by-step setup.

This page is the public root of the bot's API. The Discord integration lives at /api/interactions; the scheduled jobs live at /api/check-prices, /api/server-status, and /api/amp-status (all require a bearer token).
